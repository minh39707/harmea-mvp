## Đã làm

- Thêm `AuthProvider`/`useAuth`: tải `GET /api/auth/session` khi app khởi động, giữ user/profile trong React state và dùng chung session cho storefront/admin. Không thêm lưu auth vào `localStorage` hoặc `sessionStorage`.
- Thêm `/login`, `/register`, `/account`, `/account/orders`, `/account/orders/:id`; trang hồ sơ sửa tên/điện thoại/địa chỉ mặc định và đổi mật khẩu. Danh sách đơn có phân trang; chi tiết hiển thị người nhận, thiết kế và lịch sử trạng thái qua `shared/order-status.ts`.
- Kiểm tra `?next=` chỉ nhận đường dẫn cùng site bắt đầu `/`, từ chối `//`, dấu `\\` và control characters. Form kiểm tra email, mật khẩu 8–128 ký tự và xác nhận mật khẩu; hiển thị lỗi API, gồm thời gian `Retry-After` khi server trả 429.
- Thêm shell SPA cho route tài khoản và `/checkout`. Checkout đăng nhập tự điền địa chỉ mặc định; checkbox chỉ gọi `PATCH /api/me` sau khi đơn tạo thành công. Checkout guest vẫn hoạt động. Trang success giữ tracking link và thêm link đơn tài khoản khi đã đăng nhập.
- Chuyển admin login sang AuthProvider và `POST /api/auth/session`; user role bị chặn khỏi dashboard. 401/403 từ API quản trị và endpoint ảnh đưa về login. Giữ kiểm tra session khi admin quay lại tab/hết hạn.
- Mở rộng test auth trên MySQL thử riêng để kiểm tra đăng ký → tạo đơn gắn user → xem đơn → admin đổi trạng thái → user thấy trạng thái mới. Thêm unit tests cho `safeNext` và validate form.

F3 chưa có endpoint ảnh dành cho chủ đơn; chi tiết tài khoản không gọi endpoint admin và không hiển thị preview ảnh.
