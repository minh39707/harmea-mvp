- `scripts/docker-smoke.sh` chỉ chạy runtime trên Linux, dùng image đã load. Chờ `/health` tối đa 30 giây bằng timeout, không có MySQL ở standalone; kiểm tra architecture, OS, user, EXPOSE, healthcheck, exec CMD, UID và nội dung runtime; ghi kích thước image khi thực sự chạy.
- Env sinh từ `.env.example` với password và lookup secret ngẫu nhiên trong thư mục tạm mode 0700/umask 077; không đọc hoặc sửa `.env` riêng. Copy Compose production sang thư mục tạm để `env_file: .env` không trỏ về file riêng của người dùng. Override tên container/network và build context, giữ nguyên dịch vụ, network và volume. `--no-build` cùng kiểm tra image ID bảo đảm dùng image đang được nghiệm thu.
- Mỗi lần chạy có tên project/container/network ngẫu nhiên riêng. Trap EXIT/INT/TERM chỉ cleanup container standalone, Compose volumes và network của project tạm. Trong phép thử persistence, `down` không có `-v`; chỉ cleanup cuối dùng `-v`.
- Compose smoke migrate, gọi `/ready`, tạo đơn, tải cả ảnh/preview qua API admin, đổi trạng thái và lookup allowlist. Hash ảnh và tham chiếu đơn được giữ trong volume test, đọc lại sau down/up. Kiểm tra gate tắt, DB không publish port và chỉ nối backend internal; app trong Compose cũng không publish port.
- Standalone và Compose được kiểm tra exit code 0, không OOM và thời gian stop dưới 15 giây. Log phải là JSON, có sự kiện tắt êm và không chứa fixture phone/recipient/address/music URL/password/lookup secret. Không dump raw env/config/log khi báo lỗi.
- Thêm `.gitattributes` cho LF của shell script. Shell không chạy Docker runtime trên Windows; `--help` vẫn dùng được.
