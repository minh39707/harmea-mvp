
## Env production

Đã tạo mới `D:\private\harmea.env` ngoài repo bằng `npm run env:prod -- --out D:/private/harmea.env --image hainam164/harmea-web:v1.1.0`. Không ghi đè file có sẵn, không dùng `--force`.

- Validation PASS: secret ngẫu nhiên riêng biệt, DATABASE_URL khớp mật khẩu MySQL, admin false, image đúng version, không placeholder.
- ACL Windows đã bỏ kế thừa, chỉ tài khoản Windows hiện tại có quyền; xác nhận không có ACE kế thừa. Không khẳng định mode POSIX 0600 trên Windows.
- Không in secret, không đưa nội dung env vào báo cáo/Git/image, không gửi file cho người khác. Người dùng giữ bản sao riêng và gửi file qua kênh an toàn khi bàn giao.
- Giữ LOOKUP_SECRET cùng DB khi backup/restore/cập nhật; không sinh lại env để thay env đang vận hành.
